用两天时间把博客从里到外重新拾掇了一遍，记录一下都干了些什么。

## 换主题

博客之前用的是 `minimal-black`——好看是好看，但总觉得不像个博客，UI更像是一个产品展示页。加上又欣赏了很多大佬的博客，最终确定我要一个风格化但设计上克制的博客网站，一切以内容为中心，精简花里胡哨的 UI 元素。最终敲定博客整体迁移到 `hugo-blog-awesome`，一个很纯粹的博客模板。

## 加点水墨味

主题换完是干净的白板，接下来是"中式化"，灵感取自书法——既是文字载体又是画作可以欣赏：

- 新做了一个圆形红底的 favicon/logo，取自一张书法字形，替换掉了页头图标和全套浏览器favicon
- 页头导航用了毛笔字体 [Long Cang](https://fonts.google.com/specimen/Long+Cang)，站点名用衬线体 Libre Baskerville，都通过 Google Fonts 加载
- 主页、关于页、博客列表页、装备页依次加上了各自的书法卷轴装饰图，固定在右下角，纯装饰、不挡内容，手机宽度下自动隐藏

## 粉馆小改

粉馆背景加上了一个大大的“馆”字，风格十足。那几个 UI 面板本来用的是纯色背景，改成半透明之后角落的书法图能透出来，但"饱腹值/心情/来过"这几个标签原来用的是弱化的灰色文字，衬在半透明背景上对比度直接不够看了，单独把这个面板的文字颜色改回正常色。

## 把日期改成节气

这大概是这次改动里最"没苦硬吃"的一块：把全站的数字日期换成了中国农历节气主题。大部分人逛博客不会太在意文章时间，大家都是按顺序浏览，在这里放些小心思并不影响阅读体验，反而能增添网站特色。

- 博客列表页的日期变成"[月份]·[节气]·[候名称]"，比如"仲秋·白露·鸿雁来"——节气对应的候名取自《月令七十二候集解》
- 主页"最新文章"日期：刚发的文章显示"墨迹未干/新墨初凝"，older的按"[中文年份]·[季节]"显示
- "近况"更新时间改成相对说法：今天/昨天/X天前/X周前/X月前（用大写中文数字），超过一年再回退到完整的"年·月·日"

节气日期不是随便对一张表——写了个脚本按太阳黄经反推 1990-2060 年每年节气的精确日期，存进 `data/jieqiDates.json`，再配一份节气到月份/候名的映射表 `data/solarTerms.yaml`，对照维基文库的原文核对过一遍。

## /blog 年份标题改成中文数字

同一批改动里顺手把 /blog 列表页按年分组的标题（2026、2025……）也换成了中文数字（二〇二六年之类），跟前面节气日期的调性对上。

## 正文字体换成思源宋体

前面这些都是"中式装饰"，最后一步是正文字体也配上——把主页、/blog 列表、单篇文章、关于/装备/粉馆几个页面的正文统一换成了思源宋体（走 Google Fonts 的 Noto Serif SC 版本），logo 和导航菜单保留原来专门挑的英文/毛笔字体不变。这几个页面共用同一个 `.wrapper` 容器，一条 CSS 规则就全覆盖了，比想象中省事。

## 回顾

两天下来主要是体力活：搬迁移、调细节、核对节气数据，中间被 Hugo 的目录规范和不严谨的字体缓存坑了两次。整体上博客现在看着更"自己"了一点，继续用 Claude Code 打下手，效率确实高。
